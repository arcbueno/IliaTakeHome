# Desafio Take-Home – Flutter + Node.js

Problema a ser resolvido

Criar uma aplicação composta por um backend e um aplicativo mobile que permita o cadastro e a visualização de usuários.

Regras de negócio

1. O sistema deve permitir o cadastro de usuários com nome e e-mail.
Nome e e-mail são obrigatórios.
2. Não deve ser possível cadastrar usuários com e-mails duplicados.
3. O sistema deve permitir a visualização da lista de usuários cadastrados.
4. Cabe ao candidato decidir como estruturar o backend, o aplicativo Flutter, a persistência dos dados, validações, tratamento de erros e demais aspectos técnicos.

## Pré requisitos
1. Versionamento com Git
    1. Commits: usar front:feat: Adding new logic ou back:fix: Fixing user
2. Usar .gitignore (.env, etc)
3. Documentar via README
4. Criar testes unitários
5. Remover arquivos que não se necessita
6. Seguir REST e HTTP status
7. Separar por ambientes
8. Usar mappers
9. Usar Linters
10. Adicionar explicação das principais decisões tomadas
